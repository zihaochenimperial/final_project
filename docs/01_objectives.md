# 01 目标（Objectives）— 可证伪的部件级主张

> 2026-11-17 修订：把“卷积核可关断”改写为只看输入图像即可检验的主张。旧表述（“被遮挡卷积核沉默”）不再单独使用。

## 归因范围（先说清楚能说什么）
可归因的对象是：**新增的 1×1 读出核（每个部件一个通道）及其在输入图像上的有效感受野（ERF）**。
实际 ResNet 骨干卷积核没有被单独追踪，只能称为“骨干特征（backbone features）”，不声称“某个骨干卷积核 = 喙”。

## 主张（只用图像，成对干预：同一张图“遮挡前 vs 遮挡后”）
- **C1 选择性下降**：遮挡喙，喙通道的**原始读出分数**（pre-gate、pre-ReLU）下降，且下降量显著大于遮挡**同面积的非目标区域**（成对差）。在训练未见的填充（texture）上成立。
- **C2 其余部件保持**：对**可见且未被连带遮挡**的翅、腿等通道，分数相对变化小；与被遮挡区域有重叠的（连带遮挡）单列报告，不混入。
- **C3 分类依赖可检查**：每部件对类 logit 的贡献 = W[c,p]·证据_p 可直接读出；在部件可见的图像上，**抑制匹配通道** p 使精度的下降大于**抑制等量（一个）非匹配通道**。
- **C4（方法）LCMV 闭式读出的增量**：在**同一读出族**（同初始化、骨干、部件监督/遮挡、分类目标、预算）下，LCMV 相对“学出的读出”在 C1–C3 上有可测增益。若没有，则 LCMV 闭式读出的贡献**不成立**。

## LCMV 能保证什么、不能保证什么
- 经典推导：约束 Cᵀw=e_p 的最小方差解 w_p = R⁻¹C(CᵀR⁻¹C)⁻¹e_p（Frost/MVDR-LCMV）。
- 假设：R 正定（对角加载）、C=[s_1..s_K,1] 列满秩（K+1 ≤ 通道数且签名线性无关）、G=CᵀR⁻¹C 条件数良好。`LCMVReadout.diagnostics()` 记录 rank/cond/约束残差。
- **只约束“估计签名”上的线性响应**；签名误差、非线性、ERF 外泄都不在保证内。
- 因此：**实际遮挡下的沉默**与 **ERF 外泄**一律用测量验证（见 evaluate.py），不由推导推出。

## 研究问题与比较边界
怎样让部件读出通道在其部件被遮挡时选择性地下降，而不是靠物体内泄漏“猜”出部件？
主要比较边界（各自能解释掉什么）：
| 工作 | 近似的做法 | 对应对照 / 它能“吃掉”的贡献 |
|---|---|---|
| FAD（Towards Interpretable Face Recognition） | 滤波器对被遮挡部位不敏感的损失 | `fate_learned`：同族 + 擦除损失；若与 LCMV 相当 → 贡献只剩擦除损失（已有思想） |
| Interpretable CNN（ICNN） | 互信息滤波器损失使卷积核对应部件，无需标注 | 外部基线（待接入官方实现）；比较部件选择性与精度代价 |
| CompositionalNets | vMF 部件字典 + 遮挡离群模型 | 外部基线（待接入）；比较遮挡下的精度与可检验性 |
| MPM / 部件监督 | 用部件监督提升鲁棒性 | `multitask`：同部件监督、无擦除/零陷；若相当 → 增益来自部件监督 |
| Cutout 增广 | 随机遮挡 | `cutout`：同遮挡量、仅分类损失 |

## 由对照结果决定“原创贡献与档位”（预先约定）
1. `multitask` 或 `cutout` 在 C1–C3 上与 FATE 相当 → 增益由部件监督/增广解释，无方法创新。
2. `fate_learned` ≈ `fate`（LCMV）→ 闭式零陷不成立；贡献降为“擦除损失 + 评估协议”，按 B 或协议类工作评估。
3. 仅当 `fate`（LCMV）在 RIVAL10 与 CUB 两个数据集上、未见填充下，对 `fate_learned`、`multitask`、`cutout`、`bottleneck` 都在 C1/C2/C3 上占优，且干净精度代价 ≤ 1 点，才谈 B+ 以上；**A 档还需**更大规模验证，且在 stage‑1 证据出来之前不做任何档位承诺。

## 非目标
- 不宣称干净精度 SOTA；不声称骨干卷积核级可解释；ERF 先作定位诊断，ERF 正则、R50、全矩阵延后到 stage‑1 判定之后。
