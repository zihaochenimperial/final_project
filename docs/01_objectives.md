# 01 目标（Objectives）

## 总目标
让 CNN 高层的部件卷积核**可关断**：部件被遮挡时对应卷积核真正沉默，其余卷积核不受影响，分类由各部件证据组合得出。

## 研究问题
怎样让部件卷积核在部件被遮挡时沉默，而不是靠物体内泄漏"猜"出部件？

## 可检验的主张（H1–H4）
- **H1 帕累托占优**：干净 Top-1 相对同骨干基线下降 ≤ 1 个点，同时部件遮挡 Top-1、沉默率、Part Specificity 同时提升。
- **H2 零陷有效**：LCMV 读出的线性泄漏 |w_pᵀs_q|（q≠p）近似 0，且 PS 高于同参数线性探针。
- **H3 沉默不是增广副作用**：增益不能被同遮挡量的 Cutout 增广完全解释。
- **H4 轮廓签名更准**：签名来源 部件轮廓 > 通用边缘 ≈ 仅区域（三臂对照；若相反则证伪"轮廓特异性"）。

## 交付物
1. 方法：LCMV 零陷读出 + 反事实遮挡沉默/稳定损失 + ERF 约束。
2. 评估协议：沉默率、他核稳定性、匹配通道抑制特异性、CNN 版 PS、自然缺失 vs OOD 遮挡分离。
3. 实验：RIVAL10（机理）、CUB（主表）、可选 PartImageNet++。
4. 目标档位：稳 CCF-B，达到降档阈值以上则冲 A（见 02_protocol.md 降档规则）。

## 非目标
- 不宣称干净精度 SOTA。
- 第一篇不含视频追踪、医学扩展、稀疏高分辨率路由。
